# 💊 Smart Medicine Packing System

A full-stack medicine ordering application built with MERN stack.

## 🚀 Features
- User Authentication & Authorization
- Medicine Catalog & Search
- Shopping Cart & Orders
- Prescription Management
- Responsive Design (Mobile, Tablet, Desktop)

## 🛠️ Tech Stack
- **Frontend**: React, Vite, CSS3
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: JWT

## 📦 Installation

### Backend
```bash
cd backend
npm install
npm run dev
